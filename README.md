# منصة كوتش صحة 🏋️‍♀️🍎

منصة تفاعلية للمتدربات تشمل خطط تغذية، تمارين رياضية، متابعة أوزان، ومحادثة مباشرة مع المدربة.

## 📁 هيكلية المشروع
تم تقسيم المشروع لضمان سهولة التطوير والصيانة:
- **`index.html`**: واجهة المستخدم الرئيسية.
- **`assets/css/`**: ملفات التصميم مقسمة (ألوان، نصوص، مكونات).
- **`assets/js/`**: ملفات النظام البرمجي (فايربيس، مصادقة، لوحة التحكم، الواجهة).

## 🚀 طريقة التشغيل للعمل المحلي (Localhost)
لأن المشروع يستخدم `ES Modules` (ميزة `import/export`)، لا يمكنك فتح الملف مباشرة بالنقر عليه. 
يجب تشغيله عبر سيرفر محلي:
1. إذا كنتِ تستخدمين VS Code، ثبتي إضافة **Live Server**.
2. اضغطي كليك يمين على `index.html` واختاري **Open with Live Server**.

## 🌍 الرفع والنشر (Deployment)
المشروع جاهز للرفع المباشر على **GitHub**.
بعد الرفع على قيت هاب، قومي بربط المستودع (Repository) في **Vercel** وسيعمل تلقائياً بدون أي إعدادات إضافية.
